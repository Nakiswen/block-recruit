# Product Overview

BlockRecruit is a decentralized Web3 recruitment platform that combines AI and blockchain technology to solve hiring challenges in the Web3 industry.

## Core Features

- **AI-Powered Matching**: Resume parsing, evaluation, and intelligent job matching using RAG (Retrieval Augmented Generation)
- **Blockchain Verification**: On-chain skill certification and NFT-based achievement proofs
- **Smart Interviews**: AI interviewer with automated scoring
- **Web3 Identity**: Decentralized identity (DID) integration with wallet-based authentication

## Key Components

- Resume upload and parsing (PDF, DOCX, OCR support)
- Job posting and matching with weighted scoring
- Vector database (Pinecone) for semantic search
- NFT minting for verified credentials
- Application tracking system

## Target Users

- Web3 job seekers looking for blockchain/crypto positions
- Companies hiring for Web3 roles
- Recruiters in the blockchain space
